Position-Velocity Joint MPC Split Demo

This demo reads an NC/G-code file, interpolates fixed-cycle target position and velocity, then splits the X motion between the long axis and the galvo. The final laser output is enabled only when the NC laser command is on and all motion constraints are satisfied.

Input

NC file: complex_position_velocity_joint_mpc_input.nc
Cycle time Ts: 1000 us
Samples K: 6110
MPC horizon: 60 samples, 60.0 ms

Split Equations

target_x[k] = axis_x[k] + galvo_x[k]
target_y[k] = galvo_y[k]
target_vx[k] = axis_vx[k] + galvo_vx[k]
target_vy[k] = galvo_vy[k]

Limits

Max target speed: 110.0 mm/s
Axis velocity / acceleration limit: 110.0 mm/s / 1800.0 mm/s^2
Galvo square field: +/-11.0 mm
Galvo velocity limit: 4500.0 mm/s
